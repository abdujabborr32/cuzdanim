# Cüzdanım 👛

Kart ve nakit paranı takip eden basit, tek dosyalık web uygulaması.

- Kart ve nakit bakiyesi ayrı ayrı
- Gelen para, harcanan para, kategoriye göre harcama çubukları
- Karttan nakite (ATM) aktarım
- Veriler tarayıcıda (localStorage) saklanır, sunucu gerekmez

## Kullanım
`index.html` dosyasını tarayıcıda aç.

## GitHub Pages ile yayınlama
Repo > Settings > Pages > Branch: `main` / `(root)` > Save.
